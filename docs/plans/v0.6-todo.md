## Keymap decisions (v0.6)

- **Ctrl+K** stays `KillToLineEnd` (readline / bash / Pi muscle memory).
- **Ctrl+Shift+K** opens the command palette (F015). Initial attempt
  to bind palette on plain Ctrl+K broke `ctrl_k_kills_to_line_end`
  e2e test; the Shift variant preserves both memories.
- **Ctrl+F** opens transcript search (F019). Original `/` binding
  collided with empty-input slash-command autocomplete.
