# nini v0.6 — UX Gap Fixes Plan

> 端到端 tmux 体验调研后发现的 P0/P1 UX 缺陷，按 "用户能跑通工作流 → 对齐 Pi → 超越 Pi" 分三档里程碑落地。目标：从 v0.5.0 的"CHANGELOG 漂亮但用户卡壳"升级为 v0.6 的"用户能完成基本工作流"。

端到端体验调研发现的 18 项问题，按严重度排序为：6 项 P0（用户根本看不到做了啥 / README 失真）、6 项 P1（核心交互降级）、6 项 P2（与 Pi 的 UX 差距）。本计划先解决全部 P0 与 P1，再推进 P2。

**Last updated:** 2026-09-22
**Version:** 1
**Project ID:** `b4e2c8f1-9a3d-4e57-b6c2-7f8d5e1a3c9b`
**Target release:** nini v0.6.0

## Scope

### In scope

**Milestone 1 — 让用户能完成基本工作流（P0 + P1 必修）**

- 把 `!cmd` 实际接到 `BashRunner`（现状是 stub，stdout 全丢）
- 把 `@path` 文件补全实装（现状是 stub）
- `Ctrl+L` 真打开 `ModelSelector`（现状只改状态栏字符串）
- 状态栏填 cwd / git 分支 / context% / cost（renderer 写好了，state 字段空着）
- 补齐缺失的 4 个 slash 命令：`/help` `/debug` `/status` `/editor`
- 修复 `/resume` 子目录扫描（现状永远 "No sessions found"）
- Slash 自动补全面板支持滚动（现状硬上限 8 条，藏了 15 条命令）
- Slash 命令一次 Enter 即可执行（现状需要两次：第一次 accept completion）
- 修复 `/tree` 选择器屏幕布局崩（input 框被切成 `i│put`）

**Milestone 2 — 对齐 Pi 的 UX（P2）**

- 单一、清晰、动态 footer（删 banner + F1 不再 push transcript）
- `Ctrl+D` 二次确认（防误退）
- `!!cmd` 脱敏支持（不注入 context）
- 选择器关闭后清状态栏残留字符串
- `/help` 浮层（仿 Pi）
- `State` 启动 toast 替代 banner

**Milestone 3 — 超越 Pi（可选）**

- `⌘K` / `Ctrl+K` 命令面板（VSCode 风格）
- 输入框 undo / kill ring 端到端验证
- 鼠标支持（点击、双击、滚轮）
- Kitty/iTerm2 OSC 52 图片粘贴路径
- Transcript 全文搜索

### Out of scope

- 重构 `nini-ai` provider 层
- 新增 provider（> 当前 9 个预设）
- OAuth / device-flow 认证（继续走 env API key）
- 多窗口/多 panel 布局
- 持久化主题编辑器（只加载 JSON）
- 国际化（i18n）
- 性能优化（render.rs 的 ListItem 展开，autoscroll）

### Technologies

- Rust 1.85+（与项目共源）

- `git2` 或 `std::process::Command("git", ...)`（`state.git_branch` 探测）
- 现有：`tokio`、`serde_json`、`pulldown-cmark`、`chrono`、`uuid v7`

### Testing

- 现有：532 unit + integration tests
- 新增：`tests/scenarios/` 剧本级 E2E（insta snapshot）
- 新增：`tests/tui_snapshots/`（ratatui TestBackend 渲染对比）

## Workflow Rules

- **优先级**：M1 全部 P0/P1 → M2 → M3。不得跳级。
- **每完成一个 feature**：`cargo test` 全绿 + tmux 端到端冒烟 + CHANGELOG 一行。
- **不允许再做 stub**：函数体返回 `vec![]` / `None` / `"not yet implemented"` 的新代码必须 review。
- **每个 feature 一次 PR**：标题 `feat(<scope>): <F00X short slug>`，正文引用本计划 UUID。

## Risks

| 风险 | 缓解 |
|---|---|
| BashRunner 用 `std::process::Command` 阻塞后可能拖累 TUI event loop | 用 `tokio::task::spawn_blocking` 包裹；runtime.rs 的 submit_user_input 已经跑在异步上下文里 |
