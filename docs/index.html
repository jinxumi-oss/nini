Looking for the Rust version of the Pi coding agent? This is it.

Pi agent 的 Rust 版本 —— Pi coding agent, rewritten in Rust.

nini 是 Pi（Mario Zechner 写的 TypeScript AI coding agent）的 Rust 重写版：同样的 session JSONL v4 格式、同样的 23 条斜杠命令、同样的 settings schema，用一个 6.7 MiB 的单文件二进制代替整套 Node.js 工具链。没有账号，没有云，没有遥测。

也常被搜作： Pi agent Rust Pi coding agent Rust rewrite Rust implementation of Pi Rust 版 Pi agent Pi 的 Rust 版本 Pi agent 的 Rust 版本 Pi 的 Rust 实现
按标签找：pi-agent pi-coding-agent pi-agent-rust

GitHub 仓库 下载二进制 快速开始 中文 README

它和 Pi 一样在哪

会话格式JSONL v4，与 Pi 兼容
斜杠命令Pi 的 23 条 builtin 全部具备，另加 5 条 nini 自己的扩展（不计入 parity）
配置settings.json / models.json / skills/ —— 原样读取
内置工具bash、read、write、edit、grep、find、ls
ProviderOpenAI 兼容 / OpenAI Responses / Anthropic / Google / DeepSeek / Groq / Mistral / Cohere
安装Rust 1.85+，单个静态二进制，无运行时

装上它

curl -fsSL https://raw.githubusercontent.com/jinxumi-oss/nini/main/install.sh | sh
nini

没有 API key 也能先跑起来：nini --provider fixture 走内置的假 provider。

致敬

Pi 是原作，nini 是译本。 让这个项目有价值的一切——agent loop、session 格式、命令面、settings schema、 压缩算法，以及「保持小巧、保持无聊、保持本地」的整套哲学——都由 Mario Zechner （@badlogic）与 earendil-works/pi 的维护者与贡献者 设计出来。没有 Pi 就没有 nini。谢谢你们。

为了让这份欠债可核验而不只是一句声明，Pi v0.85.1 的源码被固定在本仓库里 （references/pi-0.85.1/，422 个文件，每个都带 sha256 锁）， 指向它的每一条符号引用（写下时 340 条，由脚本实时复算）每次跑门禁都会重新解析。

nini 是独立实现，与 Pi 项目无隶属关系，也未获其背书。 nini 里的任何错误由我们自己承担，与 Pi 无关。

不做什么

不做 OAuth / 设备流登录，不做扩展运行时，不做云端分享，不做语法高亮。 不支持的 flag 与命令是**带着原因明确拒绝**，而不是收下就丢。
