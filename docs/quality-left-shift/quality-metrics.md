# 阶段4：质量指标与验收口径（Quality Left-Shift）

## 0. 指标定义

本节定义质量左移的四项指标（仅此四项，不增删），统一口径后用于阶段验收记录与前后对比。各指标给出计算口径与依据，依据来自方案「质量左移」与视频设定的 0.5% 回退率口径。

### 0.1 拦截命中率

- **计算口径**：拦截命中率 = 约束门实际拦截的坏改动数 ÷ 被检查的改动总数。
- **依据**：来自方案「质量左移」的拦截门（阶段1 已落地：约束模块 R1–R4 + edit/write 写工具前约束门 + 工具级回归测试）。分子为约束门判定为坏改动并被拒绝/回退的改动条数；分母为该周期内被约束门检查的改动总数（以门运行产生的检查次数为分母）。分子、分母均以实际运行记录计数，不作自报通过。

### 0.2 回退率

- **计算口径**：回退率 = 因改动失败回退次数 ÷ 该周期内最终稳定版改动总数，设定口径约 0.5%（占比）。
- **依据**：来自方案「质量左移」与视频设定的 0.5% 回退率口径。分子为因改动未通过约束检查而回退、未进入稳定版的改动次数；分母为该周期内最终进入稳定版的改动总数，与拦截门运行周期对齐以保证口径自洽。回退率作为质量左移达成度的子判定项，口径上限为 0.5%。

### 0.3 无效轮次减少

- **计算口径**：无效轮次减少 = 引入方案前后「无效轮次（review/返工/失败修复轮次）」减少量 ÷ 总轮次（相对基线）。
- **依据**：来自方案「质量左移」与视频设定中「质量左移应减少无效轮次」的口径。分子为同一基线周期内引入方案后相对引入前的无效轮次减少量（非负值）；分母为对应引入方案后的总轮次（引入前后同口径周期对比）。该指标用于衡量门与验证对返工轮次的削减。

### 0.4 质量左移达成度

- **计算口径**：质量左移达成度 = 拦截命中率、回退率达标、无效轮次减少三项子指标的复合指标，取算术平均，范围 [0,1]：达成度 =（拦截命中率达标判定 + 回退率达标判定 + 无效轮次减少达标判定）÷ 3。三项子指标各自按「达标计 1、未达标计 0」判定。
- **依据**：综合三项子指标形成对「质量左移」整体收益的复合度量，保证口径自洽：全部达标为 1（完全达成），任一子指标未达标则达成度低于 1。其中回退率达标判定对照设定口径 0.5%（回退率 ≤ 0.5% 判达标）；拦截命中率达标与无效轮次减少达标判定以阶段1/阶段2 运行采集的基线与预期目标为准，目标值在实施后统一。

## 1. 记录方式与采集

**只读采集约束**：指标采集不修改实现语义、不新增依赖、不改动任何既有测试，不向运行时注入指标值；指标在门运行/测试运行结束后记录结果，只读读取门运行与测试结果为采集依据。

### 1.1 记录位置与采集方式

- **记录位置**：阶段4 指标留档文件（按阶段记录采集结果，汇总于阶段4）；留档文件只读存放采集结果与口径，不含任何运行时注入。
- **采集方式**：以只读方式运行门与测试（采集命令见 1.2），从运行输出中按 §0 口径只读计数，运行后写入指标留档，而非在运行时注入指标值。

### 1.2 可采集的采集命令（只读）

- 阶段1 门运行（只读，验证约束门与回归）：
  - `cargo test -p nini-tools`
  - `cargo test -p nini-core --lib constraint`
  - `cargo test --workspace`（全量回归只读，可选）
- 阶段2 功能验证运行：功能地图 → 运行时验证清单对应的真实运行（只读运行与输出采集）。
- 阶段4 汇总：汇总阶段1、阶段2 采集结果，形成引入前后基线对比（只读统计留档）。

指标统计内容：被检查改动总数（门运行检查次数）、实际拦截坏改动数、回退/稳定版改动计数、总轮次与无效轮次（review/返工/失败修复轮次），按 §0 口径计算后写入留档。

## 2. 与验收对照

### 2.1 对照 AC6

计划验收标准 AC6「质量指标可记录对比」= 建立基线，实施前后对比并留档。本阶段按 §0 统一口径采集指标，在阶段4 汇总形成基线对比留档，使质量指标可记录、可对比，达成 AC6。

### 2.2 对照各阶段采集点

- 阶段1（门运行）：采集拦截命中率（约束门实际拦截数 / 被检查改动总数）与回退率（门拦截导致的回退），作为基线之一；采集点 = 约束模块测试（`cargo test -p nini-core --lib constraint`）与工具级回归测试（`cargo test -p nini-tools`）。
- 阶段2（功能验证运行）：采集总轮次与无效轮次（review/返工/失败修复轮次），作为基线之一；采集点 = 功能地图 → 运行时验证清单的真实运行。
- 阶段4（汇总）：汇总阶段1、阶段2 采集结果，统一口径形成引入前后基线对比并留档，作为最终对比依据。

## 3. 诚实标注

- 指标口径为设计口径：§0 各指标的计算口径、达成判定与 0.5% 回退率目标均为设计定义，非实际运行数据；实施后须按同一口径采集实际数值，最终以实际采集数值为准。
- 回退率约 0.5% 为视频设定的口径（设定值），非实测结果；实际解读时必须结合实际运行数据——低回退不等于没有缺陷，而是质量左移指标形态（拦截先行、坏改动不进主干、自动合并修复），不得反向推断「无缺陷」。
- 无效轮次、总轮次与基线的取值须在阶段4 汇总时统一口径（同周期、同统计方式），避免因口径不一致导致对比失真；口径不一致时先统一口径再对比，不强行拼接不同口径数据。
